# 风格 Profiles

> **版本**: v1.0.1
> **用途**: 在没有明确品牌规范、用户要求推荐风格，或需要生成多个设计方向时，提供可执行的审美起点

## 使用规则

- profile 是方向起点，不是套皮模板；最终仍要回到用户目标、媒介、资产和 `aesthetic thesis`。
- profile 不是 theme；需要配色、布局或 token 化交接时，继续读取 [视觉风格 Primitives](visual-style-primitives.md)。
- 默认选择 2-3 个差异明显的 profile，差异必须体现在布局、字体、密度、图像策略或动效之一，而不是只换颜色。
- 每个方向只能保留 1 个主记忆点；若 profile 混合，必须说明主 profile 和辅助 profile，不能平均混搭。
- 有品牌规范、既有设计系统或真实产品页面时，先继承品牌，再只借用 profile 的空间、密度或叙事方法。
- 输出设计方向时，避免只说“极简 / 高级 / 科技感”；要写清具体视觉语言、风险和最小 demo 计划。

## Profile 速查

| Profile | 适合 | 主风险 |
|---|---|---|
| 信息建筑型 | 复杂信息、知识库、B2B、数据解读 | 过冷、缺少记忆点 |
| 编辑叙事型 | 报告、长内容、观点型页面、发布解读 | 版式漂亮但流程弱 |
| 工具效率型 | Dashboard、运营工具、编辑器、内部系统 | 太像默认组件库 |
| 产品发布型 | 新品演示、发布片、官网首屏、概念展示 | 过度营销化 |
| 东方留白型 | 文化、艺术、生活方式、沉静品牌 | 信息密度不足 |
| 温暖生活型 | 消费品、社区、亲子、健康、服务体验 | 甜腻或低幼 |
| 实验视觉型 | 创意活动、艺术项目、音乐、潮流发布 | 炫技压过可读性 |
| 高密度智能型 | AI 工具、控制台、情报分析、多状态系统 | 复杂到无法扫描 |

## 信息建筑型

- 适用场景: 复杂产品介绍、知识库、数据解读、B2B 方案、研究报告。
- aesthetic thesis: 用清晰结构和克制细节让复杂内容显得可信、可导航、可复述。
- 字体倾向: 稳定的正文体 + 稍有性格的标题体；数字和标签要清楚。
- 色彩策略: 中性色底、少量高对比 accent、状态色只服务分类和优先级。
- 空间/布局语法: 明确网格、分区标题、索引感导航、信息块之间有可解释距离。
- 图像/材质策略: 优先图表、截图、真实结构图；少用氛围图。
- 动效策略: 只用于层级展开、定位跳转和状态变化，不做装饰性漂浮。
- 主记忆点: 一套让人一眼看懂信息关系的结构骨架。
- 禁止事项: 不用大面积视觉噪声遮住信息，不把所有内容塞成同等权重卡片。
- 验证重点: 第一屏能否回答“这是什么、给谁、主要价值在哪里”。

## 编辑叙事型

- 适用场景: 观点页面、年度报告、品牌故事、演讲视觉、长内容摘要。
- aesthetic thesis: 像一本有主编判断的专题，把信息组织成有节奏的阅读路径。
- 字体倾向: 有辨识度的 display 标题 + 舒适长文正文；注意行长和段落节奏。
- 色彩策略: 低饱和主色、明确黑白灰层级、用少量强调色做章节焦点。
- 空间/布局语法: 大标题、跨栏图、引文、章节编号、留白与密集段落交替。
- 图像/材质策略: 使用真实摄影、扫描质感、版面裁切或档案感素材。
- 动效策略: 滚动出现、章节转场和图片揭示；不要让动效打断阅读。
- 主记忆点: 一个强标题系统或标志性章节版式。
- 禁止事项: 不把文章拆成一堆无关卡片，不用花哨背景降低正文可读性。
- 验证重点: 用户能否顺着版面读完核心论点，并记住一个观点。

## 工具效率型

- 适用场景: Dashboard、运营后台、编辑器、数据录入、工作台、AI 工具界面。
- aesthetic thesis: 把重复操作和高频判断做得安静、紧凑、稳定，视觉存在感让位于效率。
- 字体倾向: 高可读 UI 字体，数字、表格、标签和按钮字号稳定。
- 色彩策略: 功能色明确，背景干净，危险/成功/提醒状态不可混淆。
- 空间/布局语法: 左右分栏、工具栏、表格、筛选、状态面板；密度高但分组清楚。
- 图像/材质策略: 少装饰图，多真实数据、图标状态、缩略图和预览。
- 动效策略: 即时反馈、加载、拖拽、展开收起；动画短且不阻塞操作。
- 主记忆点: 一个高效的主工作区和稳定控件系统。
- 禁止事项: 不做营销 hero，不用大卡片堆低信息密度，不把按钮做成不明含义的装饰。
- 验证重点: 关键任务路径是否少点、可扫、状态明确。

## 产品发布型

- 适用场景: 新品展示、功能发布、概念 Demo、硬件/软件亮点页、发布会页面。
- aesthetic thesis: 用一个清楚的产品瞬间制造记忆，把价值、形态和关键动作对齐到同一焦点。
- 字体倾向: 强标题体 + 简短说明文字；标题要像发布话术但不空泛。
- 色彩策略: 从产品或品牌资产提取主色，背景服务产品轮廓和截图可见性。
- 空间/布局语法: 强首屏、产品大图、功能节奏、局部特写、对比或 before/after。
- 图像/材质策略: 优先真实产品图、UI 截图、局部特写；没有真实资产时诚实标注 placeholder。
- 动效策略: 首屏 reveal、产品旋转/切换、功能聚焦；控制在少数高影响时刻。
- 主记忆点: 一个可截图传播的产品画面。
- 禁止事项: 不用空洞大词替代产品事实，不用手画假产品冒充真实资产。
- 验证重点: 产品是否第一眼可见，文案是否经得起事实核验。

## 东方留白型

- 适用场景: 文化、艺术、茶酒香、生活方式、展览、沉静型品牌。
- aesthetic thesis: 用留白、节制和材质让画面有呼吸感，把注意力放在少量真实内容上。
- 字体倾向: 稳重标题字 + 细致正文；中英文混排时控制比例和行距。
- 色彩策略: 暖白、墨色、木石纸等低饱和体系，点色必须少而准。
- 空间/布局语法: 大留白、低密度、非对称平衡、细线分隔、竖向或窄栏节奏。
- 图像/材质策略: 真实器物、纸张、木纹、墨迹、影像边缘；材质轻，不抢文字。
- 动效策略: 缓慢淡入、视差轻微、镜头呼吸；不做强弹跳。
- 主记忆点: 一个安静但有质感的空白关系。
- 禁止事项: 不把“东方”做成符号堆砌，不滥用红金、印章、祥云等直白装饰。
- 验证重点: 留白是否服务内容，而不是让页面显得空。

## 温暖生活型

- 适用场景: 消费服务、社区、亲子、健康、餐饮、轻量工具、个人品牌。
- aesthetic thesis: 用柔和但清楚的视觉降低距离感，让用户感觉这件事容易开始。
- 字体倾向: 友好的圆润或人文气质字体；标题不过度幼态。
- 色彩策略: 暖色或自然色为基底，配一个清晰行动色，避免全屏糖果色。
- 空间/布局语法: 中等留白、清晰 CTA、真实场景片段、流程分步。
- 图像/材质策略: 优先真实人物/场景/产品细节；插画只在内容确实轻松时使用。
- 动效策略: 轻微反馈、柔和进入、步骤完成状态；不要拖慢任务。
- 主记忆点: 一个让人愿意点击或开始的亲近入口。
- 禁止事项: 不使用过甜插画和泛用笑脸图，不让温暖变成低可信。
- 验证重点: 视觉是否亲近但仍专业，CTA 是否清楚。

## 实验视觉型

- 适用场景: 创意活动、音乐/影像、艺术项目、潮流品牌、概念探索。
- aesthetic thesis: 用一个明确的视觉实验制造冲击，但让信息读取仍有锚点。
- 字体倾向: 可以使用强烈 display、变形字或超大字号，但正文必须可读。
- 色彩策略: 高对比、反常规组合或有限色爆发；必须控制主次。
- 空间/布局语法: 非对称、断裂网格、重叠、裁切、局部失衡；保留阅读锚点。
- 图像/材质策略: 强裁切、噪点、扫描、3D、抽象图形或实时生成视觉。
- 动效策略: 可做强节奏、突变、视差或交互实验，但只围绕一个概念。
- 主记忆点: 一个难以误认的视觉机制。
- 禁止事项: 不用随机炫技堆满页面，不牺牲核心文字和操作。
- 验证重点: 用户是否能在 3 秒内知道主题，并在冲击后读到关键信息。

## 高密度智能型

- 适用场景: AI Agent、监控控制台、情报分析、多模型状态、复杂任务编排。
- aesthetic thesis: 把大量状态、推理线索和行动入口组织成可控的智能驾驶舱。
- 字体倾向: 清楚的 UI 字体 + 等宽数字/代码片段；层级必须严格。
- 色彩策略: 深浅均可，但状态色必须稳定；用少量发光或高亮表达活跃区域。
- 空间/布局语法: 多面板、时间线、日志、队列、关系图、可折叠详情。
- 图像/材质策略: 真实日志、任务卡、图谱、模型状态和输出预览；少用抽象机器人图。
- 动效策略: 流式输出、状态推进、任务排队和告警变化；节奏服务理解。
- 主记忆点: 一个能看见系统正在思考和执行的状态层。
- 禁止事项: 不把“智能”做成蓝紫赛博背景，不用假数据堆复杂感。
- 验证重点: 关键状态是否可扫描，用户能否知道下一步该做什么。

## 混合规则

- 推荐混合方式: `主 profile + 1 个辅助手段`，例如“工具效率型 + 编辑叙事型的章节节奏”。
- 禁止混合方式: 同时叠加多个强风格的字体、颜色、纹理和动效，导致没有主记忆点。
- 若用户只说“高级”，优先给 3 个不同解释：克制可信、编辑质感、产品发布，而不是默认深色科技。
- 若用户只说“科技感”，优先追问或判断是工具效率、高密度智能、产品发布还是实验视觉；不要直接套深蓝霓虹。
