# 产品方向工作流输入模板

> **版本**: v1.0.0
> **用途**: 用于产品方向定位、MVP 切分和验证路径设计这个高频使用场景，帮助一次性给出高质量输入
> **边界**: 本文档不负责工作流路由；工作流应由目标 Skill 根据“目的”和“提供的信息”判断

## 适用场景

- 场景名称：`产品方向定位 / MVP / 验证路径设计`
- 一句话需求：`我已经知道要做产品方向梳理，但给你的材料还不够完整，希望你减少追问并直接进入分析`
- 我这次想做什么：`基于已有场景材料，输出候选方向、推荐优先级、MVP 边界和验证路径`
- 我最关注什么：`方向是否收敛、主链是否清晰、MVP 是否不失控、验证路径是否可执行`
- 我希望最终得到什么结果：`direction_brief、方向判断，必要时附主链拆解表`

## 建议提供的信息

- 背景信息：`这件事为什么要做、现在处于什么阶段、结果给谁使用`
- 现有材料：`场景描述、业务目标、痛点、现有流程、已有方案、PRD、用户反馈、实验数据`
- 关键约束：`时间、资源、数据、组织协作、输出格式、是否要衔接专利或汇报`
- 判断标准：`你希望重点判断方向优先级、能力优先级、MVP 还是验证路径`
- 参考样例（可选）：`认可的产品方向文档、方向库条目、brief、汇报材料`
- 其他补充（可选）：`业务主链、当前卡点、已有资产、已有专利或技术方案`

## 可直接复制输入模板

我现在要处理的场景是：`产品方向定位 / MVP / 验证路径设计`。
这次希望你直接帮我完成：`基于下面材料收敛产品方向，并进一步切出 MVP 和验证路径`。
我最关注的是：`方向是否优先正确、MVP 是否失控、是否能直接衔接后续产品或专利动作`。
我希望最终拿到的结果是：`一版 direction_brief，必要时附核心主链拆解表和下一步建议`。

为避免你来回追问，我先把关键信息一次性给你：

- 背景信息：`{补充为什么要做这次方向判断、现在处于什么阶段、谁会使用结果}`
- 现有材料：`{补充场景描述、业务目标、痛点、现有流程、已有方案、PRD、反馈、实验数据}`
- 关键约束：`{补充时间、资源、数据、保密要求，以及是否要继续衔接专利或汇报}`
- 判断标准：`{补充你更想判断方向优先级、能力优先级、MVP 还是验证路径}`
- 参考样例（可选）：`{补充认可的方向文档、brief、条目或汇报样例}`
- 其他补充（可选）：`{补充业务主链、当前最卡节点、已有资产或专利布局}`

如果信息已经足够，请直接进入最合适的处理流程；不要先给我解释有哪些工作流，除非你确实无法判断。

## 裁剪规则（可选）

- 如果你只关心“先做什么”，可弱化验证与专利上下文。
- 如果你已经有稳定主链，可要求直接输出增强版 `核心主链拆解表`。
- 如果你更关心能力建设而不是页面功能，请在输入里明确说明。
